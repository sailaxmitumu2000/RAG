# RAG End-to-End Pipeline


An end-to-end **Retrieval-Augmented Generation (RAG)** system for AI-powered knowledge retrieval and summarization.

---

## 🚀 Features

- Ingest multiple document formats (CSV, PDF, text)
- Semantic search with embeddings
- Hybrid search (keyword + vector similarity)
- RAG-based answer generation using LLMs
- Jupyter Notebook demos for experimentation

---

## 🛠 Tech Stack

- Python 3.11
- FastAPI
- LangChain
- FAISS / Chroma
- OpenAI GPT APIs
- Jupyter Notebook for demos
